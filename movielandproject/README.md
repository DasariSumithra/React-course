# 🎬 MovieLand Search

A responsive movie search application built with **React** and **Vite** that allows users to search for movies using the **OMDb API**. The application displays movie posters, titles, release years, and other details in a clean, user-friendly interface.

## 🚀 Live Demo

👉 https://react-movieland-search.vercel.app/

## 📂 GitHub Repository

👉 https://github.com/DasariSumithra/ReactMovielandSearch

---

## ✨ Features

* 🔍 Search movies by title
* 🎞️ Display movie posters
* 📅 Show movie release year
* ⚡ Fast and responsive UI
* 📱 Mobile-friendly design
* 🎨 Clean and modern interface

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/DasariSumithra/ReactMovielandSearch.git
```

Navigate to the project folder:

```bash
cd ReactMovielandSearch
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 🏗️ Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
